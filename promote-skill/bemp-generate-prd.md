# bemp-generate-prd 反向构建提示词

## 核心功能
BEMP票据系统需求文档(PRD)智能生成，将会议纪要、需求草稿、原型图转为结构化PRD。三角色审查补全业务规则(票据业务专家)、合规细节(票交所合规审查员)与交互体验(体验审查员)。核心价值：把"缺斤少两"的需求补全成信息完整、结构清晰、符合票交所规范的协作基准文档。

## 关键实现逻辑
- 五阶段流程：Phase1文档转换→Phase2图片识别(如有)→Phase3需求提取→Phase4三角色审查→Phase5生成输出
- Phase1文档转换：支持.docx(优先bemp-advanced-doc-generator转换)/.txt/.md/粘贴文本/图片
- Phase2图片识别：Vision能力识别UI截图/原型图，按票据操作页面/列表页面/通用页面选择模板
- Phase3需求提取：用户原文一字不改，AI补充用【补充】标记，按票据业务模块组织
- Phase4三角色审查：票据业务专家(规则库bill-business-rules.md)、合规审查员(compliance-rules.md)、体验审查员(ux-rules.md)，按需求分类筛选相关规则
- 迭代机制：v1初版→用户确认→v2已确认内容移入正文→v3+继续迭代

## 输入输出参数
- 输入：需求源文件(.docx/.txt/.md/粘贴文本/图片)
- 输出：主文档`[OriginalStem]-v{N}.md`、待确认清单`[OriginalStem]-待确认-v{N}.md`
- 输出路径：与源文件同级目录，粘贴文本输出到output/

## 主要业务流程
1. 检测输入类型，转换文档格式，提取图片
2. 图片识别(如有)：Vision能力+强制模板，识别票据字段/按钮/状态
3. 需求提取：保持原文+【补充】标记，按模块组织
4. 三角色审查：业务专家查CRUD/状态流转/金额校验；合规审查员查报文规范/ECDS/风控；体验审查员查二次确认/输入校验/空状态
5. 生成主文档+待确认清单(阻塞项/建议项/提示项)

## 技术特性
- 需求分类：自动识别涉及模块/票据类型/交易类型/涉及页面，指导审查范围
- Phase1.5门控：图片数量匹配检查
- 原始内容保护原则：用户原文一字不改，AI补充明确标记
- 票交所合规优先：所有补充内容符合上海票据交易所规则
