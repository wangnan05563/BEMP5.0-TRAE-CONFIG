# BEMP 环境变量设置指南

> **版本**: v2.0.0 | **更新日期**: 2026-07-22
> **变更原因**: env-config.json v2.0.0 敏感信息脱敏，密码不再设默认值，需通过环境变量注入

## 概述

从 env-config.json v2.0.0 开始，所有敏感信息（密码）不再在配置文件中设默认值，必须通过环境变量注入。本文档说明如何设置必要的环境变量。

## 必须设置的环境变量（敏感信息）

以下环境变量**必须设置**，否则相关功能无法正常运行：

### 数据库密码

```powershell
# Oracle 数据库密码
$env:ORACLE_PASSWORD = "你的Oracle密码"

# MySQL 数据库密码
$env:MYSQL_PASSWORD = "你的MySQL密码"
```

### 测试账号密码

```powershell
# BEMP 测试账号统一密码
$env:BEMP_TEST_PASSWORD = "你的测试账号密码"
```

## 可选设置的环境变量（有默认值）

以下环境变量有默认值（在 env-config.json 的 environmentDefaults 中），如需覆盖可设置：

### 测试账号用户名（默认值已配置）

```powershell
# 普通柜员账号（默认: wangnan02）
$env:BEMP_TEST_USER_DEFAULT = "wangnan02"

# 法人管理员账号（默认: mllzs01）
$env:BEMP_TEST_USER_ADMIN = "mllzs01"

# 机构管理员账号（默认: wangnan01）
$env:BEMP_TEST_USER_BRANCH_ADMIN = "wangnan01"
```

### 服务端口（默认值已配置）

```powershell
# Redis 端口（默认: 6379）
$env:BEMP_REDIS_PORT = "6379"

# ZooKeeper 端口（默认: 2181）
$env:BEMP_ZK_PORT = "2181"

# SpringBoot 端口（默认: 8010）
$env:BEMP_BACKEND_PORT = "8010"

# 前端端口（默认: 8091）
$env:BEMP_FRONTEND_PORT = "8091"

# 调试端口（默认: 5005）
$env:BEMP_DEBUG_PORT = "5005"
```

### 银行配置（默认: hnnxbank）

```powershell
# 银行代码（默认: hnnxbank）
$env:BANK_CODE = "hnnxbank"

# 银行项目目录（默认: ext-hnnxbank）
$env:BANK_PROJECT_DIR = "ext-hnnxbank"

# 银行URL前缀（默认: /hnnxbank/）
$env:BANK_URL_PREFIX = "/hnnxbank/"

# 切换银行示例
$env:BANK_CODE = "huisbank"
$env:BANK_PROJECT_DIR = "huisbank"
$env:BANK_URL_PREFIX = "/huisbank/"
```

## 快速设置脚本

将以下内容保存为 `.env-bemp.ps1`，在开发前运行：

```powershell
# ===== 必须设置（敏感信息）=====
$env:ORACLE_PASSWORD = "123456"       # 替换为实际密码
$env:MYSQL_PASSWORD = "root"          # 替换为实际密码
$env:BEMP_TEST_PASSWORD = "888888"    # 替换为实际密码

# ===== 可选设置（覆盖默认值）=====
# 如需切换银行，取消注释并修改
# $env:BANK_CODE = "hnnxbank"
# $env:BANK_PROJECT_DIR = "ext-hnnxbank"

Write-Host "✅ BEMP 环境变量已设置" -ForegroundColor Green
Write-Host "   - ORACLE_PASSWORD: 已设置" -ForegroundColor Yellow
Write-Host "   - MYSQL_PASSWORD: 已设置" -ForegroundColor Yellow
Write-Host "   - BEMP_TEST_PASSWORD: 已设置" -ForegroundColor Yellow
Write-Host "   - BANK_CODE: $env:BANK_CODE" -ForegroundColor Cyan
```

## 永久设置（推荐）

将环境变量添加到系统环境变量中，避免每次手动设置：

```powershell
# 以管理员身份运行 PowerShell
[System.Environment]::SetEnvironmentVariable("ORACLE_PASSWORD", "你的密码", "User")
[System.Environment]::SetEnvironmentVariable("MYSQL_PASSWORD", "你的密码", "User")
[System.Environment]::SetEnvironmentVariable("BEMP_TEST_PASSWORD", "你的密码", "User")
```

## 验证设置

```powershell
# 验证敏感信息已设置
if ([string]::IsNullOrEmpty($env:ORACLE_PASSWORD)) { Write-Host "❌ ORACLE_PASSWORD 未设置" -ForegroundColor Red }
else { Write-Host "✅ ORACLE_PASSWORD 已设置" -ForegroundColor Green }

if ([string]::IsNullOrEmpty($env:MYSQL_PASSWORD)) { Write-Host "❌ MYSQL_PASSWORD 未设置" -ForegroundColor Red }
else { Write-Host "✅ MYSQL_PASSWORD 已设置" -ForegroundColor Green }

if ([string]::IsNullOrEmpty($env:BEMP_TEST_PASSWORD)) { Write-Host "❌ BEMP_TEST_PASSWORD 未设置" -ForegroundColor Red }
else { Write-Host "✅ BEMP_TEST_PASSWORD 已设置" -ForegroundColor Green }
```

## 配置文件变更说明

| 配置项 | v1.0.0（旧） | v2.0.0（新） | 变更原因 |
|--------|-------------|-------------|---------|
| ORACLE_PASSWORD | 默认值 "123456" | 默认值 ""（空） | HC-01 敏感信息脱敏 |
| MYSQL_PASSWORD | 默认值 "root" | 默认值 ""（空） | HC-01 敏感信息脱敏 |
| BEMP_TEST_PASSWORD | 默认值 "888888" | 默认值 ""（空） | HC-01 敏感信息脱敏 |
| bank节点 | 硬编码 hnnxbank | 环境变量占位符 | HC-03 银行配置动态化 |
| services端口 | 固定数值 | 环境变量占位符+默认值 | HC-04 端口环境变量化 |
| test_config.json用户名 | 硬编码 wangnan02等 | 环境变量占位符 | HC-05 测试账号统一化 |
