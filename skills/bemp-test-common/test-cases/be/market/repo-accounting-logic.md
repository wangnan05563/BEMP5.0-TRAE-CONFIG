# P0 测试用例 - 修改票据回购记账逻辑

> 需求：河南农信"修改票据回购记账逻辑"
> 关联需求编号：V202301.02.089
> 银行环境：hnnxbank（河南农信）
> 个性化路径：/hnnxbank/

## 需求概述

1. 正回购（BT02）业务的新增/修改申请页面中，"回购金额"字段灰显不可修改，值自动等于票面总额
2. 逆回购提交申请时，后端校验回购金额必须等于票面总额，校验失败提示"回购金额必须与票据(包)总额一致"
3. 配置参数 `be.market.bt02_amt_eq_buyamt` 从 0 改为 1

## 变更文件清单

| 文件 | 变更说明 |
|------|----------|
| banks/hnnxbank/be/market/quote/sale/BT02.vue | 卖出端正回购-回购金额灰显(readonly=true)+watch totalAmt同步buyBackTotalAmt |
| banks/hnnxbank/be/market/quote/rebuy/RBT02.vue | 回购端逆回购-回购金额灰显(readonly=true)+watch totalAmt同步buyBackTotalAmt |
| served/.../RebuyValidateUtil.java | 逆回购提交校验：bt02_amt_eq_buyamt=1时回购金额必须等于票面总额 |
| served/.../SaleValidateUtil.java | 卖出端提交校验：bt02_amt_eq_buyamt=1时回购金额必须等于票面总额 |
| TM_BUSINESS_PARAMETER | be.market.bt02_amt_eq_buyamt 从 0 改为 1 |

## 测试页面路径

- 场内业务子系统 -> 市场交易 -> 对话报价申请（卖出变更/回购变更）
