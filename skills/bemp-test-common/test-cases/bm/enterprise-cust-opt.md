## 一、企业客户维护优化

### TC-CUSTCORP-010 企业客户维护-默认查询本机构及下级

```yaml
用例编号: TC-CUSTCORP-010
用例名称: 企业客户维护页面默认查询本机构及下级机构创建的客户信息
所属模块: 企业客户维护
优先级: P1
前置条件:
  - 后端服务已启动(端口8010)
  - 前端服务已启动(端口8091)
  - 已以某机构用户登录系统（如分行用户）
  - 该机构及其下级机构已创建企业客户数据
  - 其他无关联机构也创建了企业客户数据
  - 已导航至【业务管理子系统】-【客户管理】-【企业客户管理】-【企业客户维护】页面
测试类型: 功能测试
执行步骤:
  - 步骤1: 进入企业客户维护页面，观察默认查询结果
  - 步骤2: 检查查询结果中客户数据的创建机构
  - 步骤3: 确认是否包含下级机构创建的客户数据
  - 步骤4: 确认是否包含无关联机构创建的客户数据
预期结果:
  - 页面初始化自动查询并展示本机构及下级机构创建的企业客户信息
  - 查询结果中仅包含本机构及下级机构创建的客户数据
  - 不包含无关联机构创建的客户数据
  - 数据隔离规则正确生效
  - 无TypeError/ReferenceError控制台错误
  - API请求使用个性化路径前缀
可执行性: 独立可执行
```
