## 一、机构管理-批量复制角色

### TC-ROLE-010 机构管理-批量复制角色正常流程

```yaml
用例编号: TC-ROLE-010
用例名称: 机构管理中选中机构批量复制角色到目标机构
所属模块: 机构管理-批量复制角色
优先级: P1
前置条件:
  - 后端服务已启动(端口8010)
  - 前端服务已启动(端口8091)
  - 已以法人管理员登录系统
  - 已导航至【系统管理子系统】-【系统管理】-【机构管理】页面
  - 列表中存在一条源机构记录，该机构已分配角色A、角色B
  - 存在目标机构，目标机构当前无角色分配
测试类型: 功能测试
执行步骤:
  - 步骤1: 选中源机构所在行
  - 步骤2: 点击"批量复制角色"按钮
  - 步骤3: 验证弹出界面中源机构信息是否自动填充为当前选中行对应机构（Q-04确认：源机构=当前选中行对应机构）
  - 步骤4: 点击"目标机构号"超链接，在弹出框中选择目标机构
  - 步骤5: 确认目标机构号和目标机构名称正确回显
  - 步骤6: 点击"确定"按钮
  - 步骤7: 查询目标机构的角色分配情况
预期结果:
  - 弹出【批量复制角色】界面，源机构为当前选中行对应机构
  - 选择目标机构后，目标机构号和目标机构名称正确回显
  - 目标机构名称灰显，不可修改
  - 确定后目标机构获得角色A、角色B，与源机构角色一致
  - 新增角色覆盖旧角色，查询界面刷新
  - 无TypeError/ReferenceError控制台错误
可执行性: 独立可执行
```
