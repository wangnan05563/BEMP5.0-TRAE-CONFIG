## 一、机构批量导入

### TC-BRANCH-010 批量导入机构-正常流程

```yaml
用例编号: TC-BRANCH-010
用例名称: 选择上级机构并上传合法Excel文件批量导入机构
所属模块: 机构管理-批量导入
优先级: P1
前置条件:
  - 后端服务已启动(端口8010)
  - 前端服务已启动(端口8091)
  - 已以法人管理员登录系统
  - 已导航至【系统管理子系统】-【系统管理】-【机构管理】页面
  - 已准备合法的"机构信息导入模版.xls"文件，包含3条不重复的机构数据
  - 已选择上级机构（如总行）
测试类型: 功能测试
执行步骤:
  - 步骤1: 点击"批量导入"按钮
  - 步骤2: 选择要导入的Excel文件
  - 步骤3: 确认上级机构已选择
  - 步骤4: 点击确定按钮执行导入
  - 步骤5: 观察导入结果提示
  - 步骤6: 在机构列表中查询新增的3条机构数据
预期结果:
  - 导入成功，系统提示导入成功及导入条数
  - 机构列表中新增3条机构记录
  - 新增机构的上级机构为所选上级机构
  - 无TypeError/ReferenceError控制台错误
  - API请求使用个性化路径前缀
可执行性: 独立可执行
```
