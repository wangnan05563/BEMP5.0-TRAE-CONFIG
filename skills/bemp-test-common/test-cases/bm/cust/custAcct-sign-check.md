## 模块信息

| 字段 | 内容 |
|------|------|
| 功能名称 | 企业账号同步报备状态校验 |
| 所属银行 | 河南农信 (hnnxbank) |
| 实现类 | HnnxbankCustAcctServiceImpl |
| 代码路径 | banks/ext-hnnxbank/hnnxbank-biz-as/src/main/java/com/hundsun/bemp/hnnxbank/biz/bm/cust/service/impl/acct/ |
| 页面路径 | 业务管理子系统 - 客户管理 - 企业客户管理 - 企业账号管理 |
| 路由 | /#/bm/cust/acct/custAcct |
| 变更方法 | collCustAcct()、queryAndCollCustAcct()、checkSignStatusBeforeColl() |

## 功能说明

在企业账号管理页面点击同步按钮保存账号时，对同步回来的账号进行报备状态校验：

- 若账号已报备成功（cpesSignStatus="1"）且同步回来的客户号与票据系统现有客户号不一致，提示"某某账号已报备，不允许修改客户号"
- 若账号已报备但客户号一致，允许保存
- 若账号未报备，允许保存
- ECIF广播消息（PICE070701）触发的客户号合并不做此校验

### 校验逻辑流程

```
同步账号列表
  │
  ├─ 列表为空/null → 不校验，直接保存
  │
  ├─ 收集非空账号编号
  │    └─ 无非空账号 → 不校验，直接保存
  │
  ├─ 批量查询电票签约记录
  │    └─ 无签约记录 → 不校验，直接保存
  │
  └─ 遍历每个账号
       ├─ 账号编号为空 → 跳过
       ├─ 同步客户号为空 → 跳过（不会覆盖已有客户号）
       ├─ 无签约记录 → 跳过
       └─ 有签约记录
            ├─ cpesSignStatus="1" 且 客户号不一致 → 抛异常拦截
            ├─ cpesSignStatus="1" 且 客户号一致 → 允许
            └─ cpesSignStatus!="1" → 允许
```

### 关键常量

| 常量 | 值 | 含义 |
|------|-----|------|
| CustConstant.RGST_FLAG_ONE | "1" | 已报备成功 |
| CustConstant.RGST_FLAG_ZERO | "0" | 未报备 |
| CustConstant.RGST_FLAG_TWO | "2" | 报备中 |
| CommonErrorNoConst.VALID_FAIL | - | 校验失败错误码 |
