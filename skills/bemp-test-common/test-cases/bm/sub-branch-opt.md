## 一、是否简单机构字段-新增界面

### TC-BRANCH-020 机构新增-是否简单机构字段默认"否"

```yaml
用例编号: TC-BRANCH-020
用例名称: 机构新增界面是否简单机构字段默认值为"否"
```

```yaml

优先级: P0

  - 后端服务已启动(端口8010)

  - 存在机构层级：县行营业部(非简单机构)→分理处A(简单机构)

可执行性: 需专项数据（需准备简单机构层级数据）
```
