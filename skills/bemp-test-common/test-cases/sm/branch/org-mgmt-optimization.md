## 一、机构树查询条件 - 多页面覆盖（功能点一）

> PRD要求：9个菜单页面的机构树增加查询条件（机构号、机构级别、机构名称模糊匹配）
> 已有用例仅覆盖机构管理页面（TC-BRANCH-030/031/032），需补充其余8个页面验证

### TC-BRANCH-ORG-001 机构树查询-机构管理员管理页面查询条件验证

```yaml
用例编号: TC-BRANCH-ORG-001
用例名称: 机构管理员管理页面机构树弹出框包含查询条件（机构号/级别/名称）
所属模块: 机构管理员管理-机构树查询
优先级: P1
前置条件:
  - 后端服务已启动(端口8010)
  - 前端服务已启动(端口8091)
  - 已以法人管理员账号登录系统
  - 已导航至【系统管理子系统】-【系统管理】-【机构管理员管理】页面
  - 系统中已存在至少3条机构数据（含不同机构号、不同级别、不同名称关键字的机构），用于验证查询功能
测试类型: 功能测试
执行步骤:
  - 步骤1: 点击新增或修改管理员，弹出编辑界面
  - 步骤2: 点击机构选择弹出框
  - 步骤3: 验证机构树界面是否包含机构号、机构级别、机构名称三个查询条件
  - 步骤4: 在机构号输入框输入已知完整机构号（如"1001"），点击查询
  - 步骤5: 在机构名称输入框输入部分名称关键字（如"营业"），点击查询
  - 步骤6: 在机构级别下拉框选择一个级别（如"支行"），点击查询
  - 步骤7: 同时输入机构号和机构级别，点击查询
预期结果:
  - 机构树弹出框包含机构号、机构级别、机构名称三个查询条件
  - 机构号查询为精确匹配，输入完整机构号"1001"后仅定位到机构号为"1001"的1条机构，不返回"10010"等前缀匹配
  - 机构名称查询为模糊匹配，输入"营业"可匹配到所有名称包含"营业"的机构（返回条数>=1）
  - 机构级别查询为下拉选择，筛选对应级别的机构（返回条数>=1且所有结果机构级别均为"支行"）
  - 机构号+机构级别组合查询时，结果同时满足两个条件（AND关系）
可执行性: 独立可执行
```
