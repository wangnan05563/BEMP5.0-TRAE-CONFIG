## 附录：关键数据库查询汇总

### A1. 查询机构树结构

```sql
SELECT BRCH_NO, BRCH_NAME, PARENT_BRCH_NO, BRCH_LEVEL, CPES_BRCH_CODE, ORG_CODE
FROM TM_BRANCH
WHERE LEGAL_NO = '000010'
ORDER BY BRCH_LEVEL, BRCH_NO;
```

### A2. 查询机构角色分配

```sql
SELECT br.BRCH_NO, b.BRCH_NAME, r.ROLE_NAME
FROM TM_BRANCH_ROLE br
LEFT JOIN TM_BRANCH b ON br.BRCH_NO = b.BRCH_NO
LEFT JOIN TM_ROLE r ON br.ROLE_ID = r.ID
WHERE br.LEGAL_NO = '000010'
ORDER BY br.BRCH_NO, r.ROLE_NAME;
```

### A3. 查询管理员角色

```sql
SELECT ur.USER_NO, u.USER_NAME, u.BRCH_NO, r.ROLE_NAME
FROM TM_USER_ROLE ur
LEFT JOIN TM_USER u ON ur.USER_NO = u.USER_NO
LEFT JOIN TM_ROLE r ON ur.ROLE_ID = r.ID
WHERE u.LEGAL_NO = '000010' AND u.USER_TYPE IN ('2','4')
ORDER BY ur.USER_NO, r.ROLE_NAME;
```

### A4. 查询无角色机构

```sql
SELECT BRCH_NO, BRCH_NAME
FROM TM_BRANCH
WHERE LEGAL_NO = '000010' AND BRCH_LEVEL IN ('3','4')
AND NOT EXISTS (SELECT 1 FROM TM_BRANCH_ROLE br WHERE br.BRCH_NO = TM_BRANCH.BRCH_NO)
ORDER BY BRCH_NO;
```

### A5. 查询系统参数

```sql
SELECT PARAM_KEY, PARAM_NAME, PARAM_VALUE
FROM TM_BUSINESS_PARAMETER
WHERE LEGAL_NO = '000010'
ORDER BY PARAM_KEY;
```
