#### 3. bemp-generate-prd — PRD 需求文档生成

| 属性 | 值 |
|------|-----|
| **目录** | `bemp-generate-prd/` |
| **触发词** | `生成PRD`、`生成需求文档`、`完善需求`、`会议纪要转需求` |
| **版本** | v1.1.0 |

**核心能力**：BEMP 票据系统 PRD 智能生成。将会议纪要、需求草稿、原型图转为结构化 PRD。三角色审查（业务专家/合规审查员/体验审查员）自动补全业务规则、合规细节与交互体验。

**关键特性**：
- 三角色审查机制 — 业务逻辑 + 票交所合规 + 交互体验
- 增量迭代 — `v1` 初版含待确认清单，确认后生成 `v2`，逐步收敛
- 原文保护 — 用户原文一字不改，AI 补充用 `【补充】` 标记

**协作关系**：
- `bill-requirement-analyst`（智能体）→ 需求分析梳理
- `bemp-generate-prd`（本技能）→ 输出结构化 PRD
- `bemp-advanced-doc-generator` → 从 PRD 生成详细设计与测试用例

**关键文件**：
- `references/bill-business-rules.md` — 票据业务专家规则库
- `references/compliance-rules.md` — 票交所合规审查规则库
- `references/ux-rules.md` — 票据系统体验审查规则
- `references/image-analysis-template.md` — 图片识别强制模板

#### 7. bemp-testcase-generator — 测试用例生成器

| 属性 | 值 |
|------|-----|
| **目录** | `bemp-testcase-generator/` |
| **触发词** | `测试用例编写`、`功能地图`、`优先级矩阵`、`测试数据准备` |
| **版本** | v2.0.0 |

**核心能力**：基于五步方法论（功能地图 → 优先级矩阵 → P0 用例设计 → 案例集扩展 → 测试数据准备）的系统化测试用例生成。融合 11 种测试类型与 10 种 UI 组件测试设计，通过 Playwright MCP 自动探索网站、Oracle/MySQL MCP 准备数据。

**五步工作流**：
1. 功能地图 — Playwright 自动遍历站点，生成页面清单与关系图谱
2. 优先级矩阵 — 分析核心流程与风险点，确定 P0–P3 测试优先级
3. P0 用例设计 — 正常/异常/边界/用户体验 4 类覆盖
4. 案例集扩展 — 需求影响分析 + 边缘场景 + 并发场景补充
5. 测试数据准备 — 数据库查询 + 数据缺口补充 + 就绪验证

**协作关系**：
- `bemp-testcase-generator`（本技能）→ 用例编写
- `bemp-webapp-testing` → 用例执行验证
- `bemp-implementation-engineer`（智能体）→ 数据库操作

**关键文件**：
- `references/general-test-cases.md` — 11 种测试类型 300+ 模板
- `references/component-test.md` — 10 种 UI 组件测试设计
- `references/instruction-mapping.md` — 关键词→测试类型映射表
- `test-cases/` — 按子系统组织的用例文档（207+ 条 P0 用例）
