#### 2. bemp-adapter-dev

| 字段 | 内容 |
|------|------|
| **目录** | `bemp-adapter-dev/` |
| **触发词** | 新增MessageConverter、MQ消息对接、报文字段映射、适配器开发、广播消息接收 |
| **版本** | v11.1（v202601.00 增量） |
| **依赖** | `bemp-personalized-dev` |

**核心能力**：BEMP 银行适配器 MessageConverter 规范开发。实现外围系统 MQ 报文与内部服务 DTO 的双向转换，并配套单元测试。覆盖三种报文风格：XML 报文（hnnxbank/shaoxbank）、JSON+银行基类（yibbank）、JSON 直通（qinnbank）。协议层面支持 SOAP/WS、JSON、TCP+定长头、HTTP、AMQP、SOFA RPC。

**关键文件**：
- `assets/MessageConverter.java.tpl` — MessageConverter 代码模板
- `assets/MessageConverterTest.java.tpl` — 单元测试模板
- `config/bank-config.json` — 银行报文风格配置
- `references/field-mapping-methodology.md` — 字段映射方法论
- `scripts/generate_spec.py` — 接口规约自动生成

| 字段 | 内容 |
|------|------|
| **目录** | `bemp-generate-prd/` |

#### 8. bemp-testcase-generator

|------|------|
| **目录** | `bemp-testcase-generator/` |

| **依赖** | `bemp-test-common` |

**核心能力**：基于五步方法论（功能地图 → 优先级矩阵 → P0 用例设计 → 案例集扩展 → 测试数据准备）的系统化测试用例生成。融合 11 种测试类型与 10 种 UI 组件测试设计，通过 Playwright MCP 自动探索网站、Oracle/MySQL MCP 准备数据。

3. P0 用例设计 — 正常/异常/边界/用户体验 4 类
4. 案例集扩展 — 需求影响 + 边缘 + 并发
5. 测试数据准备 — DB 查询 + 缺口补充

**关键文件**：
- `references/general-test-cases.md` — 11 种测试类型 300+ 模板
- `references/component-test.md` — 10 种 UI 组件测试设计
- `references/instruction-mapping.md` — 关键词→测试类型映射
- `scripts/generate_functional_map.py` — 功能地图生成

## 七、维护说明

- **新增技能流程**：在 `.trae/skills/<name>/` 创建目录并编写 `SKILL.md` → 在本文件 §一追加索引行 + 在对应分类下追加详细卡片 → 在 §六"任务绑定"补充（如适用）
- **版本/触发词变更**：直接修改对应卡片 §二
- **删除技能**：从 §一与 §二同步移除，并在 §六清理绑定关系
- **本文以"目录扫描为权威"**：以 `.trae/skills/*/SKILL.md` 的实际命名为准，编号顺序为推荐执行序（开发 → 质量 → 部署 → 性能 → 辅助）
