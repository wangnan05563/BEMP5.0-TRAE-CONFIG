| 检查项 | 标准 | 检查结果 |

## 审查评分标准

### 评分维度权重

| 维度 | 权重 |
|------|------|
| 完整性 | 20% |
| 格式规范 | 10% |
| 覆盖度 | 30% |
| 可执行性 | 20% |
| BEMP验证 | 20% |

### 各维度评分标准

#### 完整性（100分）

| 得分 | 标准 |
|------|------|
| 90-100 | 所有字段完整，无缺失 |
| 70-89 | 95%以上字段完整 |
| 50-69 | 90%以上字段完整 |
| <50 | 字段完整率<90% |

#### 覆盖度（100分）

| 得分 | 标准 |
|------|------|
| 90-100 | 覆盖度≥90%，BEMP验证全覆盖 |
| 70-89 | 覆盖度80-89%，BEMP验证大部分覆盖 |
| 50-69 | 覆盖度70-79%，BEMP验证部分覆盖 |
| <50 | 覆盖度<70% |

#### BEMP验证（100分）

| 得分 | 标准 |
|------|------|
| 90-100 | 5项BEMP验证全部覆盖 |
| 70-89 | 4项BEMP验证覆盖 |
| 50-69 | 3项BEMP验证覆盖 |
| <50 | BEMP验证覆盖<3项 |

### 总体评分计算

```
总体评分 = 完整性得分 × 20% + 格式规范得分 × 10% + 覆盖度得分 × 30% + 可执行性得分 × 20% + BEMP验证得分 × 20%
```

### 评分等级

| 等级 | 得分 | 说明 |
|------|------|------|
| 优秀 | 90-100 | 用例质量优秀，可直接使用 |
| 良好 | 75-89 | 用例质量良好，有少量改进空间 |
| 合格 | 60-74 | 用例基本合格，需一定改进 |
| 不合格 | <60 | 用例质量不合格，需大幅改进 |
