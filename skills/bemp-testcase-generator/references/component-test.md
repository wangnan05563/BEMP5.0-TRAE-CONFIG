## 使用说明

1. **按需加载**：根据用户指定的元素类型，只加载对应的测试设计方法
2. **灵活组合**：同一元素可能涉及多种测试类型，需组合加载
3. **业务适配**：将通用设计方法适配到具体业务场景
4. **编号规范**：使用 TC-{模块缩写}-{序号} 格式编号
